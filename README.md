# MIRRA — Demo Web

Esta es la versión web de demostración de **MIRRA**, una aplicación desarrollada en Flutter para la gestión académica de estudiantes universitarios.

## 🔗 Demo en vivo

👉 [https://mirra-demo-two.vercel.app](https://mirra-demo-two.vercel.app)

## ¿Qué es MIRRA?

MIRRA permite a los estudiantes:

- Gestionar materias (notas, créditos, estado y prerrequisitos)
- Controlar el semestre actual
- Visualizar la malla curricular
- Consultar el historial académico
- Ver estadísticas de avance y promedio
- Usar el módulo asistente **Turing**

## Notas

- Esta es una versión **web de demostración**.
